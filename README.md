# Kanji Sky Defense — tuần 4

Nối DOM cho bản chơi một mục tiêu. Gom token màu, định dạng trạng thái game. Bổ sung khung sửa hồ sơ và tiến độ; co form trên mobile. Ghép vòng lặp Canvas, nhận đáp án và Katakana. Đưa storage ra mô-đun trang; đọc an toàn khi JSON lỗi.

## Chạy bản tuần này

Phục vụ thư mục này bằng máy chủ HTTP tĩnh. Mở index.html để kiểm tra luồng chơi đã tích hợp.

Chạy độc lập: `node experiments/check-engine.cjs` và `node experiments/check-storage.cjs`.

## Việc còn thiếu

Bản chơi chỉ có một mục tiêu, điểm cố định, tốc độ còn phụ thuộc frame; chỉ chuyển được vài Romaji mẫu.
